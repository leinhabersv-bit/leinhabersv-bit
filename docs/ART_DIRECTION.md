**Author:** RITHIK SV (@leinhabersv-bit)

---

## 1. Core Thesis & Design Philosophy
Traditional developer profiles often suffer from two extremes: either an unstyled utilitarian dump of raw text, or a generic template cluttered with neon orbs, arbitrary GitHub stats, and dozens of decorative badges. 

**SIGNAL / FORM** establishes a third paradigm: the GitHub profile as an **experimental digital art exhibition** and **independent design publication**. 

Software engineering, interaction design, computational geometry, and systems architecture are treated as interconnected expressions of the same underlying creative discipline.

- **SIGNAL:** The invisible underlying telemetry, state machines, Directed Acyclic Graphs, and mathematical physics loops.
- **FORM:** The visible typographic structure, kinetic vector trajectories, parametric curves, and tactile feedback.

## 3. Typographic System & Optical Hierarchy
1. **Monumental Wordmark (`RITHIK SV`):**
   - Letterforms set with high optical density (`font-weight: 900`, `letter-spacing: -3px`), filled with a subtle multi-stop gradient shifting from `#FFFFFF` through `#F1F0EA` to electric chartreuse `#C8F75A`.
2. **Architectural Subtitles:**
   - Monospaced technical flags (`// CORE_MONOGRAPH`, `SIGNAL / FORM // 2026 EXHIBITION`) set in tracking `1.5px` to provide technical grounding.
3. **Editorial Body Typography:**
   - Standard clean system sans-serif (`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto`) ensuring immediate readability on all GitHub client viewports without external font dependencies.
4. **Technical Metadata:**
   - High-contrast monospaced notation for file hashes, stack footprints, and execution statuses.

## 4. Computational Geometry & Visual Metaphors
Every geometric asset in `assets/` is derived from an actual engineering concept:

1. **Flagship Hero (`hero.svg`):**
   - Parametric Lissajous harmonic resonance curves ($x = \cos(3\theta), y = \sin(2\theta)$) mapped onto polar coordinates, representing browser frame cycles and interactive geometry.
2. **Panic Delivery (`panic-delivery.svg`):**
   - Kinematic drift slip-angle trajectory curves, velocity vector arrows, hold-to-charge parabolic projectile arcs, and cargo classification matrices.
3. **ClientLaunch (`clientlaunch.svg`):**
   - Local-First on-device storage boundary diagram (IndexedDB persistence) paired with a high-fidelity proposal workbench UI mockup frame.
4. **EventHub-CC (`eventhub.svg`):**
   - Distributed campus node constellation network linked to a three-stage Cheerio web scraping and normalization pipeline.
5. **MIC LearnPath (`mic-learnpath.svg`):**
   - Topological Directed Acyclic Graph (DAG) state progression showing locked vs. mastered prerequisites.
6. **How I Build (`philosophy.svg`):**
   - The Three Axioms: Zero Latency Persistence, Mathematical Aesthetics, and Evidence Before Claims.
7. **Monogram (`monogram.svg`):**
   - Interlocking 'S' and 'V' glyphs generated via continuous vector coordinates with coordinate anchor nodes.

## 5. Native SVG Performance & Motion Budget
- **Zero External Fonts or Scripts:** All SVGs render reliably via GitHub's Camo image proxy without font-loading layout shifts.
- **Restrained Motion:** Uses native CSS `@keyframes` (`signalSweep`, `pulseNode`) for subtle light sweeps and pulse details.
- **Accessibility:** Built-in `@media (prefers-reduced-motion: reduce)` media query zeroes all animations for users with motion sensitivity.
