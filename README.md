#### 001 // CHAMP VIRTUAL PHYSICS LAB — 9 Syllabus-Aligned Simulation Workbenches

<div align="center">
  <a href="https://github.com/leinhabersv-bit/champ-virtual-physics-lab">
    <img src="./assets/projects/champ-lab.svg" alt="CHAMP Virtual Physics Lab Exhibition Banner" width="100%" />
  </a>
</div>

- **Overview:** A high-fidelity, web-based physics laboratory simulation platform engineered specifically for university engineering students taking the **VIT Chennai BAPHY105 Engineering Physics Lab** curriculum. Replaces theoretical spreadsheets with interactive, mathematically rigorous simulation workbenches that feature real-time error propagation, least-squares linear regressions, and dynamic Canvas 2D wave visualizations.
- **Architectural Highlights:**
  - **9 Specialized Workbenches:** Fully functional modules covering Laser Diffraction (determination of slit width & grating element), Hall Effect (charge carrier concentration & Hall coefficient), Numerical Integration (trapezoidal & Simpson rules), Torsional Pendulum (rigidity modulus), Ultrasonic Interferometer, and Quantum Tunneling.
  - **Analytical Math Rigor (KaTeX):** In-situ mathematical formula evaluation displaying analytical transmission coefficients $T(E)$, dynamic wave numbers $k$, and diffraction intensity envelopes $I(\theta) = I_0 (\frac{\sin \beta}{\beta})^2 \cos^2 \alpha$.
  - **Mathematical Boundary Verification:** Rigorously guarded by **132 automated Vitest tests across 26 test suites** verifying physics calculations against standard physical constants and laboratory tolerances.
  - **Dynamic Wave Mechanics:** Real-time 60fps HTML5 Canvas 2D rendering of quantum barrier tunneling and interference fringes with interactive parameter modulation.
- **Exhibition Links:** [📂 Open Source Repository](https://github.com/leinhabersv-bit/champ-virtual-physics-lab) • [🔬 Portfolio Case Study](https://developer-portfolio-eta-steel.vercel.app/work/champ-virtual-physics-lab)

### CHAPTER 02 // HOW I BUILD: THE THREE AXIOMS

<div align="center">
  <img src="./assets/systems/philosophy.svg" alt="How I Build — Engineering Methodology Axioms" width="100%" />
</div>

1. **Axiom 01: Zero Latency Persistence**  
   Whenever possible, prioritize on-device state (IndexedDB) over superfluous network hops. Applications should boot instantly, store critical data locally, and never lock user productivity behind a spinner or an offline disconnect.

2. **Axiom 02: Mathematical Aesthetics**  
   Visual delight should emerge organically from computational systems: kinetic slip-angles, projectile parabolas, laser diffraction wave envelopes, and parametric 3D lattices. Visual polish is an engineering discipline, not an afterthought.

3. **Axiom 03: Evidence Before Claims**  
   Never assert performance, stability, or reliability without automated verification. Every state machine, collision boundary, physics calculation, and storage vault is guarded by automated test suites (**142+ Vitest tests passing across active projects**).
